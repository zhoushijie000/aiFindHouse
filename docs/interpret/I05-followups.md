# I05 · 政策解读后推荐追问

## 节点职责

在解读核验通过或系统返回受限说明后，依据当前政策资料生成少量下一步候选。

## 输出格式

```
候选内容：可继续追问的问题或操作，无则填“无”
操作类型：继续解读 / 查询政策 / 查看详情
政策引用：对应真实政策 ID，无则填“无”
查询条件：查询政策时填写，其余填“无”
原文依据：解读问题对应的真实段落，其余填“无”
详情入口：系统提供的真实入口，无则填“无”
验证状态：待系统验证
下一步：展示最多 3 个验证通过的候选
```

## 核心规则

- 每个候选按上述格式输出，避免重复已回答的问题，不凑数。
- 继续解读必须有完整正文和相关段落支持，不推荐原文未说明的金额、条件或材料问题。
- 缺正文时仅提供真实详情入口或可验证的政策查询，不推荐资格判定或领取承诺。
- 系统分别核验正文依据、实际查询结果及入口可用性，通过后才展示。
- 用户点选后重新识别意图，沿用有效政策引用；更换政策时重新匹配。
- 生成或验证失败时隐藏候选，保留本轮解读和输入框；查看原文后 1 天内返回恢复会话。
