# I04 · 基于完整政策原文解读

## 节点职责

系统确认唯一政策、完整正文、来源及时效后，围绕用户问题生成有原文依据的简短解读。

## 输出格式

```
政策引用：系统确认的政策 ID 与名称
政策状态：系统返回的生效状态
结论：依据完整正文回答用户问题
注意事项：原文明确的适用条件、限制与日期
原文依据：每条事实对应的真实段落引用
原文入口：系统提供的真实入口，无则填“暂不可用”
个人资格：不作判断
下一步：系统核验解读事实与引用
```

## 核心规则

- 无完整正文或仅有片段时，不调用本节点，由系统返回受限说明与真实详情入口。
- 只使用当前政策正文，不从标题、其他政策或常识补写标准、金额、材料和渠道。
- 原文未说明的问题如实告知；原文矛盾或时效冲突标为待核验，不自行裁决。
- 保留适用对象、金额、日期及限制，每条事实绑定原文依据。
- 即将生效、已失效须明确标注，不把历史解读写成当前执行。
- 不判断学区归属，不承诺个人资格、补贴或审核结果；普通回复建议 50–150 字。
- 系统核验通过后进入 I05；未通过转受限说明。接口或 AI 异常保留对象与问题，重试失败节点。
