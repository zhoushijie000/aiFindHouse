# I03 · 政策对象确认追问

## 节点职责

系统无法唯一确认政策时，仅追问必要的名称、区域或版本，保留用户原解读问题。

## 输出格式

```
追问内容：你想了解哪一项政策？可以提供政策名称，或选择已查询到的政策。
需要补充：系统判定的真实缺失项或歧义
候选内容：系统返回的真实政策名称及必要区分信息，无则填“无”
保留已有条件：是
保留解读问题：是
下一步：等待用户确认
```

## 核心规则

- 一次只问最关键的问题，已确认的名称、区域或版本不得重复询问。
- 候选只能来自系统真实结果；同名多版本仅使用已核实信息区分，不默认选最新版本。
- 政策对象确认前不解读，不预设补贴金额或申请资格。
- 不索取无关预算、收入或证件信息。
- 已知名称但查询成功零匹配时，由系统提示未找到，不编造候选。
- 用户补充后回 I02 重新提取和匹配；提出新问题时重新识别意图。
