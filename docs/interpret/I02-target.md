# I02 · 政策对象与解读问题提取

## 节点职责

提取政策对象、区域或版本线索及解读关注点，交系统匹配真实政策。

## 输出格式

```
政策名称：用户提供的名称，无则填“未指定”
政策引用：已选政策的真实 ID，无则填“无”
区域或版本：用户明确提供或有效上下文中的线索，无则填“未指定”
指代依据：所选卡片或当前会话中的明确指代，无则填“无”
解读问题：用户本轮希望了解的内容
是否更换政策：是 / 否
待确认内容：缺失或歧义，无则填“无”
下一步：匹配政策对象
```

## 核心规则

- 用户明确更换政策时更新对象；未修改的有效政策信息与关注点保留。
- “第一个政策”按已展示卡片顺序解析，不依据新排序重新绑定。
- 名称可作匹配线索，ID 只能来自系统；不将相似标题当作同一政策。
- 用户粘贴片段仅作线索，不视为完整有效原文。
- 唯一匹配后获取详情；缺失或多候选时进入 I03；成功零匹配由系统提示未找到。
- 对象或详情接口异常分别重试，不以旧缓存作为当前政策事实；本节点不解读或判断资格。
