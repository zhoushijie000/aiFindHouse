# I01 · 政策解读意图识别

## 节点职责

结合本轮问题和有效上下文，识别用户是否在咨询具体政策，交系统进入对应流程。

## 输出格式

```
意图：找房 / 楼盘咨询 / 政策查询 / 政策解读 / 未识别
是否多意图：是 / 否
其他意图：其他独立意图，无则填“无”
是否需要澄清：是 / 否
```

## 核心规则

- 询问具体政策的含义、条件或执行方式属于政策解读；查询“有哪些政策、补贴”属于政策查询。
- 寻找或筛选楼盘属于找房；咨询明确楼盘属于楼盘咨询。政策仅作找房条件时仍为找房。
- 本轮明确目标优先；“这个政策”等短句结合有效上下文识别，不凭关键词判断。
- 意图明确但政策对象不明时，进入对象提取与确认，不直接判为未识别。
- 无法归类时输出“未识别”，由系统返回固定引导。
- 仅输出识别结果，不回答政策内容、不评定个人资格。
