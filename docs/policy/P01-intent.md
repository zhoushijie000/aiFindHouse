# P01 · 政策意图识别

> 本文是依据需求文档整理的**建议输出契约**，字段名、枚举、示例 ID 均为实现建议，不表示原文已定义这些 API。所有示例仅用于演示，不代表真实政策及其内容。

## 节点职责

判断本轮问题应进入购房支持政策、找房或未识别意图分支。未识别到意图时，由系统返回固定引导，AI 不生成引导文案。识别“补贴、人才、消费券、以旧换新、房票、就学、车位”等词时结合完整语义，不能只按单个关键词强制分流。

## 触发

用户发送非空消息，或点击可发送问题的推荐入口。接收历史上下文后先识别意图，再进入对应条件提取流程。

## 输入

- `user_message`：本轮原始问题。
- `recent_turns`：必要的近期用户问题与 AI 回答。
- `active_intent`：当前会话已确认意图。
- `selected_policy_id`：用户当前选中的政策 ID；没有则为空。
- `service_scope`：后端配置的服务范围，以成都新房与成都购房支持政策为本版本依据。

## AI 输出 JSON 示例

```json
{
  "node_id": "P01",
  "intent": "POLICY_QUERY",
  "intent_changed": false,
  "request_mode": "search",
  "evidence": ["用户询问成都最近购房支持政策"],
  "reply": null,
  "next_node": "P02"
}
```

示意输入：`成都最近有什么购房支持政策？`

## 字段说明

| 字段 | 说明 |
| --- | --- |
| `intent` | `FIND_HOUSE` 找房、`PROJECT_QUERY` 楼盘解读、`POLICY_QUERY` 查政策、`POLICY_INTERPRET` 政策解读；未识别时为 `null`。 |
| `intent_changed` | 与上一轮已确认意图是否不同，供系统决定是否切换条件集。 |
| `request_mode` | 政策场景为 `search` 查询或 `interpret` 解读；其他场景可为空。 |
| `evidence` | 简短可核对的输入依据，不输出模型内部推理。 |
| `reply` | 本节点始终返回 `null`；未识别意图时的引导文案由系统固定返回。 |
| `next_node` | 查政策进入 P02；找房进入 H02；楼盘解读进入 J02；政策解读进入 I02；未识别时进入 PG。系统校验后实际执行。 |

## 约束

1. “换成锦江区呢”等短句可继承当前已确认的政策意图；不能把每轮当成独立问题。
2. 用户明确改问“300 万有什么新房”时进入找房流程；不因上轮问政策而强行留在政策流程。
3. “这个楼盘能上哪所学校”不能直接由 AI 回答学区归属。若用户实际询问已收录的就学支持政策，可转政策查询；否则说明服务边界。
4. 结合有效上下文后仍无法确定当前业务意图时，不强行路由，不临时生成澄清文案，进入系统固定引导节点 PG。
5. 未识别意图时（`intent: null`），`reply` 返回 `null`，`next_node` 指向 PG；系统统一原样返回下方固定文案，不调用 AI 生成、改写或补充。
6. 四类业务定义遵循 [共用意图识别 Prompt](../house/H01-intent.md)。政策解读和楼盘解读分别承接到新增独立流程的对象提取节点，不重复执行意图识别；从独立页面直接发起问题时才由该页的意图节点开始。

### 系统固定引导

> 安安是你的购房小助手，我可以帮你找成都新房，以及查询成都购房支持政策。你可以告诉我想买哪个区域、预算多少，或者想了解哪类购房支持政策。

返回引导后本轮不进入政策或楼盘查询，保留会话，等待用户继续提问后重新识别意图。

## 失败处理

- 意图不明确：输出 `intent: null` 与路由 PG，由系统原样返回上述固定引导。
- AI 服务异常或结构无效：系统提示“安安暂时开小差了，请稍后再试。”，允许重试并保留原消息。
- 本节点不调用政策结果概括，不输出真实政策事实。

## 验收样例

| 输入 / 上下文 | 预期 |
| --- | --- |
| “高新区有哪些人才购房支持政策？” | `POLICY_QUERY + search`，进入 P02。 |
| 已选中一条政策后说“帮我解释一下” | `POLICY_INTERPRET + interpret`，带政策引用进入 I02。 |
| 前轮查政策，本轮“青羊区 300 万有哪些新房？” | `FIND_HOUSE`，切换找房条件集进入 H02。 |
| 咨询指定楼盘的户型 | `PROJECT_QUERY`，进入 J02。 |
| “今天的篮球比分？” | `intent: null`，进入 PG；系统原样返回固定引导。 |
| “这个怎么样？”且无可用上下文 | `intent: null`，进入 PG；系统原样返回固定引导。 |
| 找房、政策混合且最终未识别出本轮业务意图 | 进入 PG，不生成其他澄清文案，不承诺补贴资格。 |

## 可复用提示词

你是成都房产超市的意图识别节点。只根据本轮消息与已确认会话状态选择业务意图；短句可继承意图，显式切换优先。不要回答政策事实、资格或金额。按给定 JSON 契约返回可供系统校验的路由建议。未识别到意图时路由 PG，reply 返回 null，不生成引导文案，由系统固定返回。
