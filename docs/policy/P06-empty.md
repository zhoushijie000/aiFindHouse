# P06 · 政策零结果引导

## 节点职责

查询成功但无匹配政策时，一次生成零结果说明与待验证候选，交系统查询验证。

## 输出格式

```
结果说明：当前政策数据中暂未找到与你的条件匹配的政策。
候选问题：依据真实政策库覆盖范围提出，无则填“无”
建议变更：逐项对应候选问题，说明调整哪些查询条件
保留条件：逐项对应候选问题，说明沿用哪些原条件
验证状态：待系统查询验证
下一步：系统展示零结果说明，后台验证后展示最多 3 个有效问题
```

## 核心规则

- 仅查询成功且结果为零时使用；接口异常不得描述为没有政策。
- 只说明当前政策数据未查到，不断言现实中不存在。
- 候选须符合真实区域、类型字典及系统能力，不编造政策或声称已验证。
- 候选文案须准确对应调整条件；涉及历史政策须明确，不静默放宽“当前有效”要求。
- 零结果说明可先展示，候选须经系统真实查询有结果后才能展示，无需再次调用 AI。
- 后台验证不修改原条件；用户选择候选后才更新条件并重新查询。
- 最多展示 3 个通过验证的问题；无候选或验证失败时保留说明及输入框，不凑数。
