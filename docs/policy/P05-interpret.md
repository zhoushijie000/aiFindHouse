# P05 · 政策原文解读

> 本文为**建议输出契约**。示例不包含真实法律政策结论；JSON 字段、引用方式及失败码是实现建议。

## 节点职责

对用户指定且经政策库查询确认的完整政策正文做忠实、简短归纳，按“结论 + 注意事项 + 政策原文入口”输出。系统必须先确认正文完整；没有正文或正文不足时不调用本 AI 节点，转到系统 PN 输出固定受限说明与真实详情入口。

## 触发

用户明确要求解读政策，或点击可解读政策的操作入口；政策 ID 已确认，业务系统已获取对应记录，并判定正文完整、可用于归纳。前置检查未通过时转系统 PN，不进入本节点。

## 输入

- `user_question`：用户希望理解的内容。
- `selected_policy`：真实政策 ID、标题、有效期和系统判定状态。
- `policy_body`：业务系统获取并确认完整的正文全文。
- `body_availability`：本节点只接受 `full`；`partial` / `missing` 由系统前置检查转 PN。
- `source_url` 或 `detail_path`：经验证的政策原文或平台详情入口。
- `source_sections`：正文段落 ID 或可靠定位，供摘要逐项核验。

## AI 输出 JSON 示例

以下输入及输出均为**虚构测试数据**，不代表任何真实政策。示意政策 A 的测试正文全文仅含两句：

- `demo-section-01`：“本测试文件用于说明政策信息查询流程。”
- `demo-section-02`：“阅读政策信息时应核对文件标注的有效期。”

```json
{
  "node_id": "P05",
  "mode": "body_summary",
  "conclusion": "示意政策 A 是用于说明政策信息查询流程的测试文件。",
  "notes": ["阅读时应核对文件标注的有效期。"],
  "source": {
    "policy_id": "demo-policy-a",
    "label": "查看政策原文",
    "route_ref": "demo-route-a"
  },
  "claims": [
    {"text": "本文件用于说明政策信息查询流程。", "section_refs": ["demo-section-01"]},
    {"text": "阅读时应核对文件标注的有效期。", "section_refs": ["demo-section-02"]}
  ],
  "individual_eligibility": "not_assessed",
  "next_node": "P07"
}
```

上例演示完整正文归纳；`demo-route-a` 只是系统已提供路径的引用占位，不是可点击的真实政策链接。结论与每项注意事项都必须附输入正文中可核验的依据。

## 字段说明

| 字段 | 说明 |
| --- | --- |
| `mode` | 本节点固定为 `body_summary`，仅归纳通过系统完整性检查的正文。 |
| `conclusion` | 对检索内容的概括，不是对用户资格或权利的最终认定。 |
| `notes` | 正文明确记载的要求、限制、日期等注意事项。 |
| `source` | 真实政策及经过系统校验的原文/详情入口引用。 |
| `claims` | 有正文时建议为 `{text, section_refs}` 列表，方便系统与评审核对来源。 |
| `individual_eligibility` | 本契约统一 `not_assessed`；不输出“用户可领取”。 |

## 约束

1. **保守解释原文冲突**：允许忠实概括查得正文；“不回答具体政策结论”限制 AI 自行推定金额、标准、个体资格及执行结果，不以自身知识补充缺失原文。
2. 无正文或正文不足时，系统前置检查直接转 PN，使用固定受限说明：“当前可以查询到该政策，但具体补贴标准和申请条件需要进入政策详情查看。”不调用 AI 从标题推导对象、补贴金额、申请渠道或材料。
3. 有正文也不能断言用户可以获得补贴。原文提到完整条件加结构化规则可准确判断的例外，本流程未实现该资格规则引擎，故不采用该例外。
4. 对已失效或即将生效的政策，先说明系统给出的状态，不让正文摘要掩盖有效期。
5. 仅有片段不进入自由解读；系统转 PN 保留真实政策详情入口，不让模型自行认定片段已经足够完整。
6. 引用入口取自业务数据。不存在可用入口时如实说明“政策详情暂不可用”，不生成假链接。
7. 不回答具体学区归属，不承诺申请审核结果。普通回答建议保持 50—150 字，完整条文由详情页承载。

## 失败处理

- 选中政策已移除：重新查询并说明条目不可用，不引用历史缓存作为当前事实。
- 正文获取失败或完整性检查未通过：不调用本节点，转系统 PN 固定受限说明并保留已验证的标题、有效期和入口；政策记录查询失败使用接口异常提示。
- 正文内容矛盾：指出相关条款需进一步核实，保留来源，不替业务系统作最终认定。
- AI 生成无依据断言：系统拒绝该输出，转系统 PN 固定受限说明及政策详情入口。

## 验收样例

| 场景 | 预期 |
| --- | --- |
| 有标题和有效期，无正文，用户问“补贴多少钱？” | 系统不调用 P05，转 PN 固定受限说明与真实详情入口。 |
| 有正文，用户问“我肯定能拿到吗？” | 不承诺；指出需核对原文适用对象与申请条件。 |
| 正文可用但政策尚未生效 | 显示“即将生效”并限定摘要含义。 |
| 原文没有申请材料 | 不自创材料清单。 |
| 只有正文片段 | 前置检查转 PN，不生成片段解读。 |

## 可复用提示词

仅在系统确认完整正文后生成内容，按结论、注意事项、原文入口组织。结论指对正文的忠实概括，不代表用户资格判断。禁止从标题、常识或其他政策补写金额和条件。每个事实应能回指输入中的正文段落；正文缺失或不足的请求交系统 PN，不输出解读。
