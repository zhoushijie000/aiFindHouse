# P02 · 政策查询条件提取

## 节点职责

从本轮问题和有效政策上下文中提取查询条件，交系统校验；不查询政策、不判断资格。

## 输出格式

```
查询区域：用户明确的区域，未提供填“未指定”
政策类型：用户明确的类型，未提供填“未指定”
时间要求：用户原始时间要求，未提供填“未指定”
指定政策：用户提供的名称或系统已有引用，无则填“无”
本轮修改：明确新增或修改的条件
待确认内容：缺失或有歧义的表达，无则填“无”
舍弃条件：无关或已被替换的条件，无则填“无”
下一步：校验查询条件
```

## 核心规则

- 本轮明确修改优先，其余有效政策条件保留；不默认继承找房预算、户型等无关条件。
- 跨业务仅在用户明确说“这个区”等可追溯指代时继承区域。
- “成都最新政策”提取为“成都全市＋最新”，不要求补齐区县和类型。
- 不自行设定最低查询条件；是否可查及默认全市范围由系统配置决定。
- “最新”是排序要求，不等于正在生效；“最近”无配置时保留原话，不自定天数。
- 用户提供的政策名称可作检索线索，政策 ID 只能引用系统真实结果；模糊指代标为待确认。
- 不推断人才等级、户籍、购房套数、补贴金额或资格。
