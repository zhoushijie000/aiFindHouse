# P02 · 政策查询条件提取

> 本文为**建议输出契约**，不是原文已有 API。示例只演示字段表达，不代表实际存在的政策。

## 节点职责

从本轮问题与有效政策上下文中提取区域、政策类型、时间要求及政策引用，生成可校验的查询条件；决定是否具备最小查询范围由系统规则完成。

## 触发

P01 已识别政策意图；用户补充条件、修改条件或选择具体政策后再次进入本节点。

## 输入

- `user_message` 与必要的 `recent_turns`。
- `policy_context`：上轮政策区域、类型、时间要求和选中政策。
- `intent_changed`：是否由找房等业务切入。
- `region_dictionary` / `policy_type_dictionary`：业务认可的区域、类型字典。
- `system_time` / `timezone`：服务端当前时间及业务时区。
- `query_capabilities`：查询接口支持的筛选、排序及政策 ID 直查能力。

## AI 输出 JSON 示例

```json
{
  "node_id": "P02",
  "intent": "policy",
  "filters": {
    "region": {"value": "锦江区", "source": "current_message"},
    "policy_type": {"value": "人才购房支持", "source": "policy_context"},
    "time_requirement": {"value": "latest", "source": "policy_context"},
    "policy_id": null
  },
  "changes": ["region"],
  "unresolved": [],
  "discarded_context_fields": ["housing_budget"],
  "next_node": "SYSTEM_VALIDATE_QUERY_SCOPE"
}
```

示意上下文：前轮查“青羊区最新人才购房支持”，本轮说“换成锦江区”。`housing_budget` 仅示意跨业务字段隔离。

## 字段说明

| 字段 | 说明 |
| --- | --- |
| `filters.region` | 行政区域或“成都全市”；原文未提供时可为空，由已公布的查询默认规则处理。 |
| `filters.policy_type` | 映射到业务字典的政策类型；原词不能匹配时保留到 `unresolved`。 |
| `filters.time_requirement` | 建议枚举 `current` 当前、`latest` 最新、`explicit_range` 指定范围、`unspecified` 未指定；指定范围需附起止条件。 |
| `filters.policy_id` | 用户选中或经业务检索确认的政策标识，不能由模型编造。 |
| `source` | `current_message`、`policy_context` 或显式 `system_default`，便于界面解释条件来源。 |
| `changes` | 本轮明确修改的政策条件。 |
| `unresolved` | 无法消歧的区域、指代、类型或时间描述。 |
| `discarded_context_fields` | 不适用于政策查询的跨意图条件。 |

## 约束

1. 仅覆盖本轮明确更改的条件；“换个区”不清楚具体区域时不随机选区。
2. 切换业务时不盲目继承房价预算、面积、户型、楼盘标签。区域也不能默认必然沿用；只有“这个区的政策”等明确指代或用户确认时才引用前轮区域。
3. “最新”表示排序与时效要求，不代表每条结果都已生效；有效状态由系统根据日期判定。
4. “成都最新政策”已具有全市范围与最新要求，不应强制要求用户继续提供区县或类型。
5. 不把“我有 300 万预算”转成补贴资格或补贴上限，不推断人才等级、户籍、购房套数等未提供信息。
6. 不自行给“最近”编造固定天数；若业务有已配置的时间规则则使用并记录来源，否则保留为时间意图，由系统决定可否按最新排序查询。

## 失败处理

- 无法映射字段或指代不唯一：交由系统最小范围校验，不满足时进入 P03。
- 本轮新条件无效：保留原会话并明确需要补充哪项，不静默执行旧条件查询。
- AI 结构化输出校验失败：重试或提示 AI 服务异常，不提交未经校验的查询。

## 验收样例

| 输入 / 上下文 | 预期 |
| --- | --- |
| “成都最新政策” | 提取成都全市 + 最新，允许进入规则校验后直接查询。 |
| 前轮青羊区人才支持，本轮“改成购房消费券” | 只修改类型，继承政策范围。 |
| 前轮找房青羊区 400 万，本轮“成都最近有什么政策？” | 使用成都全市；不继承青羊区和预算。 |
| 前轮查政策，本轮“这个也算吗？”且无选中条目 | 标记指代不清，进入必要澄清。 |

## 可复用提示词

仅提取业务接口支持的政策条件，显式修改优先于政策上下文，跨意图不盲目继承。输出条件及来源，缺失保持为空，歧义写入 unresolved。不要补写政策事实，也不要自行决定用户资格。
