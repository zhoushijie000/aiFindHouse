# H07 · 零结果候选问题

## 节点职责

楼盘查询成功但匹配数量为0时，根据接口返回的推荐楼盘数据，生成用户可以继续查询的问题。

## 输入内容

- 用户原始需求及已确认条件；

- 本轮零匹配结果；

- 接口返回的推荐楼盘及真实字段。

## 输出格式

```
候选问题：

1. 青羊区有哪些总价500万元以内的楼盘？
   关联楼盘编号：推荐楼盘实际编号
   调整说明：保留青羊区，将总价上限调整为500万元

2. 预算400万元以内，还可以看看哪些区域的楼盘？
   关联楼盘编号：推荐楼盘实际编号
   调整说明：保留400万元预算，调整意向区域
```

## 核心规则

- 仅根据接口返回的推荐楼盘生成候选问题，不得凭空扩展区域、价格或项目特点。

- 优先从推荐楼盘的区域、总价、单价、户型、面积等真实字段中提取共同特征。

- 候选问题应与用户原始需求相关，并明确调整了哪些条件。

- 生成的问题必须能够覆盖至少一个推荐楼盘，并关联对应的真实楼盘编号。

- 推荐楼盘字段缺失时，不得使用该字段生成问题。

- 最多生成3个内容不同、表达简短的候选问题。

- 生成候选问题不修改用户原有条件；用户点击后才应用新的查询条件。

- 无法根据推荐楼盘生成有效问题时，不展示候选问题，仅保留零结果说明和推荐楼盘卡片。

- 随机推荐楼盘不代表满足用户原始条件，不得表述为原条件的匹配结果。
