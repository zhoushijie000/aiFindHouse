# H06 · 零结果说明

## 节点职责

仅当楼盘接口查询成功且匹配数量为0时，生成零结果说明。接口返回的10个随机推荐楼盘由前端展示。

## 输出格式

```
查询说明：暂未找到符合当前条件的楼盘。下方为随机推荐的楼盘，仅供你浏览参考，不代表符合本次筛选条件。

下一步：生成相关找房问题
```

## 核心规则

- 仅在接口成功且匹配数量为0时执行。

- 只说明查询结果，不修改或放宽用户原有条件。

- 不在本节点生成推荐问题，由下一节点单独处理。

- 随机推荐楼盘由接口提供，不计入匹配数量，也不得描述为符合用户需求。

- 前端根据接口返回的10个随机推荐楼盘生成卡片，AI不得编造楼盘或编号。

- 零结果说明完成后，进入下一节点生成并验证相关找房问题。

- 推荐问题生成或验证失败时，仍展示零结果说明和随机推荐楼盘。

- 接口超时或查询失败属于系统异常，不得表述为“没有符合条件的楼盘”。
