# J04 · 基于真实数据解读楼盘

## 节点职责

系统确认唯一楼盘并返回有效数据后，根据用户关注点，从产品和板块两个维度生成简短解读。

## 输出格式

```
楼盘名称：示意楼盘A

产品解读：项目当前参考单价约××元/平方米，提供三室户型，建筑面积约100—120平方米。结合价格、户型、面积、容积率、绿化率和在售情况，说明项目的产品特点及适配需求。

板块解读：项目位于××区域，结合已核实的交通、商业、医疗等信息，说明项目所处板块的生活便利性及配套情况。

具体内容可以查看楼盘详情：
[接口查询到的楼盘项目ID]
```

## 核心规则

- 产品解读和板块解读分别控制在50～150字。
- 产品解读包括价格、户型、面积、容积率、绿化率及在售情况。
- 价格只能使用接口返回的真实数据，并明确单价、总价或起价口径。
- 板块解读仅包含区域、交通、商业、医疗等已核实信息。
- 不解读教育、学校、学区划分及入学资格等信息。
- 仅使用本轮接口返回的数据，字段缺失时不作说明，不得推测或补写。
- 没有地图路线数据时，不计算通勤距离或时间。
- 不使用“值得买”“升值空间大”等主观结论，不承诺投资收益。
- 楼盘项目ID只能使用接口返回的真实ID，由前端生成楼盘详情入口。
- 解读完成后直接展示回复与楼盘详情入口，不再进行解读结果校验。
- 用户继续提问后，携带楼盘对象与上下文进入下一轮意图识别。
